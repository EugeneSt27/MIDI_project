# Обработка и структурно-семантический анализ MIDI-данных 

Данный проект разработан в рамках научно-исследовательской (магистерской) работы и представляет собой автоматизированный пайплайн для извлечения структурных, гармонических и мелодических признаков из файлов формата MIDI. Цель работы — выявление паттернов развития музыкальной композиции, анализ самоподобия (Self-Similarity) и автоматическая сегментация (маркировка секций и фраз) для сравнения генеративной ИИ-музыки (например, AIVA) с произведениями классической и современной академической традиций.

## Основные возможности пайплайна

-   **Парсинг и стандартизация**: Извлечение хронологического пула нот, параметров темпа (Time Signature) и нормализация временной сетки с жесткой привязкой к долям (beats).
-   **Извлечение независимых признаков (Bar Profiles)**: Для каждого такта формируется семантический вектор, состоящий из трех подпрофилей:
    -   *Гармонический (Harmony)*: 14-мерный вектор, проецирующий аккорд на квинтовый круг (допускает плавное вычисление близости, а не бинарное совпадение).
    -   *Мелодический (Melody)*: 24-мерный вектор (распределение Pitch-Class относительно тоники + интервальная гистограмма для оценки контура мелодии).
    -   *Ритмический (Rhythm)*: 10-мерный вектор (выключен по умолчанию в `total SSM` с целью снижения зашумленности для классических произведений).
-   **Матрицы самоподобия (Self-Similarity Matrices, SSM)**: Построение полной, а также компонентных (гармонической, мелодической) матриц сходства.
-   **Novelty Detection & Segmentation**: Вычисление кривой "новизны" (Novelty Curve) через свёртку SSM с checkerboard-ядром Фосслера для точного определения границ структурных частей.
-   **Позиционный анализ фраз**: Рекурсивное сравнение фраз для классификации типов изменений (регармонизация, перемелодизация, точное повторение).
-   **Графы наследования (Inheritance Graph)**: Поиск взаимосвязей между музыкальными фразами на основе порогового сходства.

## Структура репозитория

```text
MIDI_project/
├── main.py                     # Основной скрипт запуска (pipeline)
├── requirements.txt            # Зависимости среды Python
├── README.md                   # Документация проекта
├── data/
│   ├── raw/                    # Входная директория для .mid / .midi файлов
│   └── annotated/              # Тестовые данные с разметкой
├── results/                    
│   ├── ssm/                    # Сгенерированные тепловые карты (Heatmaps) матриц SSM
│   ├── novelty/                # Графики Novelty-кривой с границами секций
│   ├── harmony_distribution.png # Гистограмма распределения внедиагональных элементов
│   └── experiment_metrics.csv  # Итоговый датафрейм с расчетными метриками для аналитики
└── src/
     ├── config.py              # Конфигурационные константы и весовые коэффициенты
     ├── midi/
     │   └── extract.py         # Парсинг MIDI-сообщений, сортировка событий
     ├── analysis/
     │   ├── features.py        # Векторизация профилей тактов (Harmony, Melody, Rhythm)
     │   ├── harmony.py         # Эвристическое определение базовой гармонии такта
     │   ├── novelty.py         # Математический аппарат поиска границ (штрафные ядра, сглаживание)
     │   ├── phrase_analysis.py # Позиционное сравнение метрик между структурными блоками
     │   ├── metrics.py         # Рассчет агрегированных метрик (Block Score, Contrast и др.)
     │   └── structure.py       # Конвертация абсолютного тика (tick) в такты (bars)
```

## Требования и запуск

1.  Установить необходимые библиотеки (рекомендуется использование виртуального окружения `conda` или `venv`):
    ```bash
    pip install -r requirements.txt
    ```
2.  Поместить исследуемые треки в папку `data/raw/`. Желательно использовать префиксы `CLASSIC_`, `MODERN_` или `AIVA_` для корректной генерации агрегированных графиков.
3.  Запустить пайплайн:
    ```bash
    python main.py
    ```
4.  Сгенерированные аналитические отчеты, графики и CSV-файлы будут доступны в директории `results/`.

## Научная ценность полученных метрик

Пайплайн позволяет получить числовое и визуальное обоснование композиционной сложности. В частности, гистограмма внедиагональных значений гармонической матрицы SSM (Harmony Off-Diagonals) позволяет доказать бинарность гармонических решений генеративного ИИ в сравнении с плавной и богатой гармонией произведений И.С. Баха или блочной структурой Л. ван Бетховена.

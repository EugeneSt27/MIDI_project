# Структурно-семантический анализ MIDI-данных 

Данный проект разработан в рамках научно-исследовательской (магистерской) работы. Представляет собой автоматизированный пайплайн для извлечения структурных, гармонических и мелодических признаков из `MIDI`-файлов. 

Цель работы — выявление паттернов развития музыкальной композиции, анализ самоподобия (Self-Similarity Matrices, SSM) и построение графов наследования для оценки качества музыкальной формы. Пайплайн предназначен для квантификации различий между генеративной ИИ-музыкой (AI-generated) и произведениями классической и современной академической традиций.

## Основные возможности пайплайна

- **Извлечение независимых признаков (Bar Profiles)**: Для каждого такта формируется семантический вектор:
  - *Гармонический (Harmony 14D)*: Проекция аккорда на квинтовый круг (Circle of Fifths). Позволяет улавливать тональную близость (например, До-мажор и Соль-мажор), а не просто бинарное совпадение.
  - *Мелодический (Melody 24D)*: Гистограмма относительного питча и интервалов, обеспечивающая инвариантность к транспозиции.
- **Матрицы самоподобия (SSM)**: Построение независимых матриц сходства (Гармония, Мелодия, Ритм) и их объединение через взвешенную сумму матриц для устранения шумов.
- **Автоматическая сегментация (Novelty Detection)**: Нарезка произведения на формальные секции и фразы с помощью алгоритма `Novelty Curve` (checkerboard kernel).
- **Позиционный анализ фраз**: Автоматическая классификация типов развития композиторской мысли: регармонизация, перемелодизация, повторение и полная смена.
- **Графовая нотация (Inheritance Graph)**: Построение хронологических ориентированных графов на основе библиотеки `networkx`. Визуализация иерархии тем и дальних заимствований (реприз).
- **Квантификация макроструктуры (Продвинутые метрики)**:
  - `harmony_entropy` — Шенноновская энтропия распределения гармонии, показывающая структурное богатство.
  - `phrase_vocabulary_richness` — Разнообразие используемых музыкальных фраз на трек.
  - `long_range_edge_ratio` — Индикатор наличия макро-реприз в графе зависимостей (то, чего лишен ИИ).

## Структура репозитория

```text
MIDI_project/
├── main.py                     # Основной пайплайн и генерация отчетов
├── requirements.txt            # Зависимости среды Python
├── README.md                   # Документация проекта
├── data/
│   └── raw/                    # Директория для входных .mid / .midi файлов
├── results/                    
│   ├── graphs/                 # Отрисованные графы наследования (networkx topological layout)
│   ├── novelty/                # Графики Novelty-кривых с границами структур
│   ├── ssm/                    # Тепловые карты SSM (как полные, так и разделенные по признакам)
│   ├── harmony_distribution.png # Сглаженный KDE-график распределения гармонии по группам
│   └── experiment_metrics.csv  # Датафрейм со всеми вычисленными композиционными метриками
└── src/
     ├── config.py              # Весовые коэффициенты для признаков
     ├── midi/                  # Парсинг и фильтрация MIDI-событий
     └── analysis/
         ├── features.py        # Векторизация профилей
         ├── metrics.py         # Вычисление графовых метрик, энтропии и метрик блочности
         ├── novelty.py         # Алгоритмы скользящего окна и поиска пиков
         ├── phrase_analysis.py # Анализ рекурсивной структуры и типов изменений
         └── similarity/        # Построение матриц сходства и графов наследования (Digraph)
```

## Требования и запуск

1. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Поместить исследуемые треки в папку `data/raw/`. Рекомендуется использовать встроенные префиксы в названии файла (например, `CLASSIC_`, `MODERN_` или `AIVA_`), чтобы код автоматически построил KDE распределения.
3. Запустить проект:
   ```bash
   python main.py
   ```
4. Сгенерированные графы, матрицы и финальная CSV-таблица будут доступны в директории `results/`.
